# fusenote

Fuse filesystem note paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/fusenote/

## Install / run

```bash
git clone https://github.com/theworker02/fusenote.git
cd fusenote
node src/cli.js
node --test
```
